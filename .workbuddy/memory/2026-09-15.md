## 环境坑（重要）
- 本机 bash 缺 coreutils，需 `export PATH="/c/Program Files/Git/usr/bin:$PATH"` 才能用 ls/grep 等。
- PowerShell 工具不回显 stdout，统一用 bash。
- **环境变量 ELECTRON_RUN_AS_NODE=1 被全局设置**，启动 Electron 前必须 `unset ELECTRON_RUN_AS_NODE`，否则 electron 以纯 node 运行、`require('electron')` 拿不到 app。
- JS 注释里不能出现 `*/n` 这类序列（会提前闭合块注释）；`(async () => {...}())` 形式的 IIFE 在本机 node 里报语法错，改用 `const run = async () => {...}; run();`。

## Windows 打包（electron-builder 26.15.3）
- 产物 `dist/icrontab-1.0.0-setup.exe`（约 112MB，NSIS 向导：可选目录、桌面/开始菜单快捷方式、卸载不删数据）。`npm run dist` 一键打包；图标由 `scripts/make-icon.py` 纯标准库生成（PNG 手写 zlib 编码 + ICO 容器，无需 Pillow）。
- **网络关键坑**：本机 Node/got 不走系统代理，GitHub 直连永久挂起（TCP 悬挂不报错）。electron-builder 会从 GitHub 下载 5 个工具包，必须预置到 `%LOCALAPPDATA%\electron-builder\Cache\<releaseName>\<filename>`：`7zip@1.0.0/7zip-win-x64.tar.gz`、`winCodeSign-2.6.0/winCodeSign-2.6.0.7z`、`nsis-3.0.4.1/nsis-3.0.4.1.7z`、`nsis-resources-3.4.1/nsis-resources-3.4.1.7z`、`icons@1.1.0/icons-bundle.tar.gz`（npmmirror 镜像 `https://npmmirror.com/mirrors/electron-builder-binaries/<releaseName>/<file>` 全部可达）。
- 另在 package.json `build.electronDownload.mirror` 固定 npmmirror 的 electron 下载源；打包命令需带 `ELECTRON_MIRROR` + `ELECTRON_BUILDER_BINARIES_MIRROR` 环境变量。
- electron zip 缓存在 `%LOCALAPPDATA%/electron/Cache/<hash>/`；打包进程若 15 分钟无日志输出即判定卡死（某请求直连 GitHub 挂起），杀掉重跑。
- 验证打包产物：`dist/win-unpacked/icrontab.exe --shot-out=xxx.png`（PowerShell 下先 Remove-Item Env:ELECTRON_RUN_AS_NODE），截图确认界面/调度器/数据加载正常。
- **NSIS 协议页乱码坑**：中文 Windows 下 NSIS 按 ANSI 代码页解析 .txt，UTF-8 中文变乱码。解法：`scripts/make-license-rtf.py` 生成 `build/license.rtf`（纯 ASCII，中文转 `\uN?`），`nsis.license` 指向 rtf；NSIS 检测 `{\rtf` 头自动按 RTF 交给 RichEdit 渲染，Unicode 正确。用写字板（同为 RichEdit）打开 rtf 截图即可验证效果。
- 原生窗口自动化/截图：`scripts/shot-screen.py`（ctypes GDI BitBlt + 手写 PNG，支持启动 exe 带参数、自动关闭）、`scripts/shot-installer.py`（EnumWindows/EnumChildWindows 找 NSIS 向导、BM_CLICK 点按钮）。**注意**：ctypes.WINFUNCTYPE 第一参是返回类型；Python 模块名不能带连字符，`shot-screen.py` 需用 importlib 加载。
