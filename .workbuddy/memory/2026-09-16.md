## 确认弹窗图标遮挡文字修复
- 现象：layer.confirm（icon:3）的问号图标压住文字。
- 根因：`renderer/css/app.css` 的 `.layui-layer-content { padding: 16px 18px !important }` 覆盖了 Layui 为带图标弹窗预留的 `padding-left: 44px`。

## 表格固定列 + 操作列吸附（第二版）
- 操作列按钮要求每行最多 2 个：`.row-actions` 用 `display:grid; grid-template-columns: repeat(2, 58px)`，不要用 flex wrap（宽度抖动，可能挤成 3 个或 1 个）。
- 关键坑：`table-layout: fixed` + `width:100%` + `min-width` 组合下，Chromium 先按 100% 容器宽分配列宽、再用 min-width 拉伸表格——**未声明宽度的自动列会被算成 0（负剩余空间）然后内容消失**。所有列必须显式声明 width。
- sticky 操作列：`th/td.col-op { position:sticky; right:0; background:#fff; }`，thead 用 `#fafbfc` 底色，配 `-10px 0 10px -8px` 左侧阴影 + `border-left` 分隔。外层 `.table-scroll { overflow-x:auto }`。
- 任务/日志/分组三个表都用 `grid fixed-cols`（min-width 920px）；帮助页表格保持自动布局。
- 操作列最终形态：宽 96px，`.row-actions .btn` 纯文字化（去边框背景、brand 色文字、hover 下划线、danger 红色），grid 两列 auto。
