## 耗时显示格式化
- 需求：日志耗时不再一律按秒显示，>60s 按分钟、>60min 按小时。
- `renderer/js/app.js`：新增 `durationFormat(ms)` 并挂到 `window.AppUtil`（<60s 保留两位小数「秒」；<1h「X 分 Y 秒」；≥1h「X 小时 Y 分」，整值时省略零尾）。日志详情弹层改用它。
- `renderer/js/pages.js`：日志列表耗时列改用 `util2.durationFormat`。
- `main/notifier.js`：新增同逻辑 `durationText(ms)`，邮件正文/HTML、桌面通知三处耗时统一替换。
- 验证：`node scripts/check.js` 54 项全过；三个文件 `node --check` 通过。

## 手动执行实时日志弹窗
- 需求：手动执行时把透明 loading 换成方形不透明弹窗，并实时显示执行日志。
- 链路：`main/runner.js` `run()` 支持 `options.onOutput(chunk)`（stdout/stderr/超时提示都会回调）→ `main/scheduler.js` `runNow(taskId, triggerBy, options)` 透传 → `main/main.js` `tasks:run` 用 `pushEvent('task:output', { taskId, chunk })` 推给渲染层（复用现有 `task:event` 通道，preload 无需改动）。
- 渲染层：`app.js` 新增 `AppUtil.runTaskLive(id, taskName, onComplete)`——480x480 layer 弹窗（标题「正在执行：#id 名称」），订阅 `api.onEvent` 过滤 `task:output` + taskId，写进 `.run-live-log`（深色终端样式）并自动滚底；结束时按 `res.log.status` 显示 成功/失败/超时 徽章 + `durationFormat` 耗时，全程无输出时兜底展示 `log.output`；`end` 回调里退订事件。任务页/编辑页两处调用点已替换（任务页用 reload 闭包里的 `result.list` 查任务名，完成后刷新列表）。
- CSS：`app.css` 新增 `.run-live / -head / -info / -log / -foot`（flex 布局，日志区 flex:1 自动撑满）。
- `bridge.js` 预览模式 `runTask` 分两次 emit `task:output` 模拟直播。
- 验证：54 项自检过；Electron 截图 `shots/run-live.png` 确认弹窗效果（成功徽章 + 输出 + 耗时）。截图前需 taskkill 已安装的 icrontab.exe（单实例锁）。

## 关闭窗口 → 最小化到托盘
- 需求：点关闭不退出软件，默认后台运行（托盘），托盘「退出」才真正退出。
- `main/main.js`：引入 `Tray, Menu`；新增 `tray/quitting/closeTipShown` 状态。`createWindow()` 里 `close` 事件：非 quitting 时 `preventDefault()` + `hide()` + `createTray()`，首次关闭发一次系统通知（点击通知可唤回主界面）。`createTray()`：托盘图标（`build/icon.png`，asar 内可直接读取）+ 右键菜单（打开主界面/退出）+ 单击唤回。`showMainWindow()` 统一处理恢复/显示/聚焦（隐藏、最小化、已销毁三种情况）。`before-quit` 置 `quitting=true` 并 `tray.destroy()`（保证托盘退出、系统关机、截图模式能真正退出）。`second-instance` 改用 `showMainWindow()`（唤起隐藏窗口）。
- `package.json`：`build.files` 加入 `build/icon.png`（否则打包后托盘无图标）。
- 验证：54 项自检过；`window.close()` 渲染层触发后 electron 进程持续存活（关闭被拦截，进入托盘模式）。注意：本环境**后台任务方式启动 electron 会因 GPU 进程无法启动而崩溃**，必须前台跑；隐藏窗口后 `capturePage` 会永久阻塞，测试托盘逻辑别用截图流程。清理 electron 进程用 PowerShell `Stop-Process`（bash 里 `taskkill //IM` 在此环境会报「无效参数」）。
